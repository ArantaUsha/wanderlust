How the plan is kept honest

Schema-locked output
The AI must return a fixed JSON shape. Anything else is rejected before it reaches the screen.
Budget checked in code
Every rupee in the plan is added up by the page. A plan over budget never shows as the result.
Read-only agent
It can suggest and calculate. It cannot book, pay or change anything outside this page.
Fallback plan
If the AI is unavailable or answers badly, a rule-based plan is shown and labelled as such.
In this MVPItinerary planning. Verification flags on timings, seasons and tickets.
Not in this MVPBooking, payments, offline use, corporate travel, loyalty programmes.
